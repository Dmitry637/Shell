# Shell Emulator — Этап 1: REPL

Минимальный прототип эмулятора командной оболочки UNIX-подобной ОС, реализованный на **Java** в одном файле `src/Shell.java`.

Проект выполнен в соответствии с требованиями **Этапа 1 — REPL**: программа работает в консоли, формирует приглашение на основе данных операционной системы, разбирает введённую команду и её аргументы, содержит команды-заглушки `ls` и `cd`, поддерживает `exit` и обрабатывает ошибки ввода.

## Цель проекта

Создать минимальную интерактивную командную оболочку, которая по принципу работы похожа на UNIX-подобный shell.

На текущем этапе основные команды `ls` и `cd` являются заглушками. Их задача — показать, что команда и её аргументы были корректно распознаны.

## Возможности

- консольный интерфейс (CLI);
- интерактивный REPL-цикл: ввод команды → обработка → вывод результата → повтор;
- приглашение вида `username@hostname:~$`;
- получение имени пользователя из системных свойств Java;
- получение имени компьютера (hostname) через `InetAddress`;
- разбор команды и аргументов вручную, посимвольно;
- поддержка одинарных и двойных кавычек;
- обнаружение незакрытых кавычек с сообщением `No closing quotation`;
- команда-заглушка `ls`;
- команда-заглушка `cd`;
- команда `exit` для завершения программы;
- сообщение об ошибке для неизвестных команд;
- обработка ситуации, когда `exit` вызывается с аргументами.

```bash

```

После запуска появится приглашение, например:

```text
student@DESKTOP-123:~$
```

Конкретные `username` и `hostname` зависят от операционной системы, на которой запускается программа.

## Поддерживаемые команды

### `ls`

Команда-заглушка. Выводит своё имя и переданные аргументы.

Пример:

```text
student@PC:~$ ls
Команда: ls; аргументы: нет
```

С аргументами:

```text
student@PC:~$ ls -la /home
Команда: ls; аргументы: -la /home
```

### `cd`

Команда-заглушка. На текущем этапе она не изменяет реальный текущий каталог, а только выводит команду и её аргументы.

Пример:

```text
student@PC:~$ cd /home/student
Команда: cd; аргументы: /home/student
```

### `exit`

Завершает работу интерактивного Shell.

Пример:

```text
student@PC:~$ exit
Shell завершен.
Программа завершена.
```

Команда `exit` не принимает аргументы:

```text
student@PC:~$ exit test
Ошибка: команда exit не принимает аргументы.
```

### Неизвестная команда

Если введена команда, которой нет в списке поддерживаемых:

```text
student@PC:~$ hello
Ошибка: неизвестная команда: hello
```

## Кавычки и парсер

В проекте реализован собственный простой парсер вместо обычного `split(" ")`.

Он умеет воспринимать текст в кавычках как один аргумент.

Например:

```text
student@PC:~$ ls "hello world"
Команда: ls; аргументы: hello world
```

В этом случае `hello world` считается одним аргументом.

Поддерживаются и одинарные кавычки:

```text
student@PC:~$ ls 'hello world'
Команда: ls; аргументы: hello world
```

### Незакрытая кавычка

Если пользователь открыл кавычку и не закрыл её, парсер сообщает об ошибке:

```text
student@PC:~$ ls "ff
No closing quotation
```

То же самое работает для одинарных кавычек:

```text
student@PC:~$ ls 'ff
No closing quotation
```

После ошибки программа не завершается и снова ожидает следующую команду.

## Как устроена программа

Основная логика находится в методе `main()`.

Общий алгоритм работы:

1. Получить имя пользователя.
2. Получить hostname компьютера.
3. Создать `Scanner` для чтения ввода.
4. Запустить цикл REPL.
5. Показать приглашение `username@hostname:~$`.
6. Считать строку пользователя.
7. Разобрать строку методом `parseCommand()`.
8. Разделить результат на имя команды и аргументы.
9. Выполнить соответствующую ветку `switch`.
10. Повторить цикл до команды `exit`.

## Основные методы

### `main(String[] args)`

Точка входа в программу. Управляет всем интерактивным циклом и обработкой команд.

### `parseCommand(String input)`

Разбирает строку на отдельные токены с учётом кавычек.

Например:

```text
ls "hello world" -l
```

преобразуется в логическую структуру:

```text
[ls, hello world, -l]
```

Если кавычка не закрыта, метод выбрасывает `IllegalArgumentException`.

### `printStub(String command, String[] arguments)`

Общий метод для команд-заглушек `ls` и `cd`. Выводит имя команды и её аргументы.

### `getHostname()`

Получает имя компьютера через:

```java
InetAddress.getLocalHost().getHostName()
```

При невозможности получить hostname используется резервное значение `localhost`.

## Ограничения текущего этапа

Это именно прототип REPL, а не полноценный UNIX shell.

На текущем этапе:

- `ls` не показывает содержимое директорий;
- `cd` не изменяет текущий каталог;
- не реализованы пайпы (`|`), перенаправления (`>`, `<`), переменные окружения и другие возможности shell;
- команды не запускаются как отдельные процессы ОС.

Эти ограничения соответствуют цели первого этапа: сначала реализовать базовый интерактивный цикл и корректный разбор команд.
